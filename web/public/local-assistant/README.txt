kivo 本地助手 1.4

需要 Node.js 22+。macOS / Linux：下载并运行 install.sh。
已安装官方 Codex CLI 的用户也可运行：
node kivo-local.mjs --root "/你的项目父目录"

首次启动会询问授权范围并显示配对码。在 kivo 网站的“本地助手”中输入此码。
网页“创建项目”可新建电脑上的文件夹；对话输入框左侧的文件夹可打开已有目录。
保持终端运行。Ctrl+C 退出会停止本地任务。网页可撤销配对。
再次启动：bash "$HOME/.kivo-local/start.sh"
重新配对：bash "$HOME/.kivo-local/start.sh" --pair

文件、Codex 进程和命令在电脑上执行，不向服务器复制整个项目。
模型上下文、任务日志和会话会发送到 kivo，按现有规则由服务器记录用量，管理员可查看会话。
本地仅保存设备凭据、Codex 会话和文本检查点；用户 OpenAI API Key 留在服务器加密存储。
默认使用 workspace-write 沙箱、关闭任务网络访问；额外命令或文件权限需要在网页批准一次。
文件面板排除 .env、密钥文件、依赖目录和符号链接。二进制文件和超过 1 MB 的文件不参与文本编辑。
检查点与 Git 独立，不修改已有仓库或提交历史。移除网页项目不会删除本机文件。

当前提供 macOS / Linux 自动安装。若系统不支持 Codex 沙箱，任务会失败，不会自动降级为无限制执行。
